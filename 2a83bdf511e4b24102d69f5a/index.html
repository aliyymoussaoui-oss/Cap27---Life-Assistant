Installer l’app

iPhone / iPad — ouvre cette page dans Safari, touche Partager (le carré avec la flèche) puis Sur l’écran d’accueil. Elle s’ouvre en plein écran et fonctionne sans réseau.
Ordinateur — Chrome ou Edge : l’icône d’installation apparaît dans la barre d’adresse.

S’abonner aux calendriers

Réglages → Calendrier → Comptes → Ajouter un compte → Autre → Ajouter un abonnement calendrier, puis Actualiser : toutes les heures.
