Installer l’app

iPhone / iPad — ouvre cette page dans Safari, touche le bouton Partager (le carré avec la flèche), puis Sur l’écran d’accueil. Elle s’ouvrira en plein écran, comme une vraie app, et fonctionnera même sans réseau : la dernière version consultée reste lisible dans le TGV.
Ordinateur — Chrome ou Edge : l’icône d’installation apparaît dans la barre d’adresse.

S’abonner

Sur iPhone : Réglages → Calendrier → Comptes → Ajouter un compte → Autre → Ajouter un abonnement calendrier, puis colle l’adresse du fichier. Le téléphone se met à jour tout seul — plus jamais de réimport.
